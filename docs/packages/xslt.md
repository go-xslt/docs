# xslt

XSLT processor over a pure-Go XML DOM (go-nokogiri) — no libxslt, no cgo.

## Install

```bash
go get github.com/go-xslt/xslt
```

Requires Go 1.26.4 or newer. `CGO_ENABLED=0`.
